Бесплатный виджет для идентификации рыбы для вашего сайта.

Предоставьте своим читателям мгновенную идентификацию рыбы: поле для загрузки фотографии с результатами ИИ, ссылками на виды и рекомендациями по приманкам — размещено на наших серверах, достаточно одного фрагмента текста для вставки. Не требуется API-ключ, не требуется техническое обслуживание, бесплатно для блогов, сайтов по аренде рыболовных снастей, магазинов рыболовных принадлежностей и форумов.

Полезно знать.

  • Для кого это предназначено: Рыболовные блоги, сайты по аренде снастей и предоставлению услуг гидов, магазины рыболовных принадлежностей, клубы и форумы. Пожалуйста, не перепродавайте это как свой собственный продукт.
  • Квота: Ваши посетители используют стандартную бесплатную квоту (3 идентификатора в день на посетителя), которая применяется к каждому IP-адресу — те же ограничения добросовестного использования, что и в основном инструменте.
  • Источник: Оставьте строку "Powered by Blue Seas Fishing" в виджете; это и есть вся цена.
  • Конфиденциальность: Загружаемые файлы передаются через наш API по протоколу HTTPS, обрабатываются только для идентификации и никогда не публикуются без разрешения. Виджет не устанавливает собственные файлы cookie для отслеживания.

Часто задаваемые вопросы

Это что-нибудь стоит?

Нет. Виджет бесплатен при условии указания авторства. Сайтам с высокой посещаемостью (более 100 000 загрузок виджета в месяц) следует использовать другой виджет. связаться с нами для выделенной квоты.

Можно ли это как-нибудь уложить?

Да — контейнер iframe принимает ваши CSS-стили (ширина, границы, радиус). Сам интерфейс инструмента размещен у нас, поэтому улучшения автоматически распространяются на каждый встроенный элемент.

Работает ли это на мобильных устройствах?

Да, он адаптивный. На телефонах, нажав на поле для загрузки, посетители могут либо сделать снимок камерой, либо выбрать уже имеющуюся фотографию из своей библиотеки.

Замедлит ли это загрузку моей страницы?

Скрипт загрузки занимает около 1 КБ, и iframe загружается с задержкой только при прокрутке до нужного места.
