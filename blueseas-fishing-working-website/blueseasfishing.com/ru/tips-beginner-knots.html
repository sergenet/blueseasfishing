Основы рыбалки: узлы, снасти и первые поездки

Изучите 3 основных узла, 3 простых оснастки и контрольный список для ваших первых нескольких выходов в море без лишних хлопот.

Реклама

Три узла, покрывающие 95%

  1. Улучшенный клинч — Быстрое движение, отлично подходит для крючков/приманок. Шаги: 5–7 витков → обратно через маленькую петлю → через большую петлю → увлажнить → затянуть.
  2. Паломар — Очень прочный для плетения кос/монокорации. Шаги: Двойная леска → простой узел → пропустить петлю через приманку → затянуть.
  3. Петлевой узел (противоскользящий) — позволяет приманкам естественно раскачиваться (джеркбейты/поверхностные приманки).

Три простых оснастки (для пресноводных водоемов)

  • Поплавок + Крючок для прудов, где выращивают мелкую рыбу и форель.
  • Нед Риг Грибовидная головка весом 1/16 унции + небольшая приманка-стик.
  • Техасская буровая установка Мягкая пластиковая приманка, не зацепляющаяся за водоросли, для ловли окуня.

Три простых способа бурения (соленая/солоноватая вода)

  • Поршень с пробкой + креветки Смертельно опасен в болотах/отмелях.
  • Джиг + Лопатка Медленно прокатывайте по дну.
  • Каролина Риг Грузило в форме яйца + поводок для ловли в течении.

Рекомендуемое стартовое снаряжение

Комбинация средней и быстрой скорости вращения Монофильная леска 8 фунтов (пресноводная) Плетеный шнур 30 фунтов (для прибрежной зоны) Поводок из флюорокарбона 20 фунтов Рыболовные плоскогубцы

Контрольный список для первой поездки

  • Местные правила и лицензия, без зазубрин там, где это необходимо.
  • Поляризованные солнцезащитные очки, шляпа, вода, солнцезащитный крем.
  • Фотоаппарат/телефон для идентификации рыбы и фотографирования перед выпуском.
