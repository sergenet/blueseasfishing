Κόκκινο τύμπανο εναντίον μαύρου τυμπάνου: πώς να τα ξεχωρίσετε

Δύο τύμπανα, δύο σιλουέτες. Μπάρα, κηλίδες και σχήμα ουράς τα διαχωρίζουν αμέσως.

Φωτογραφίστε αυτά τα χαρακτηριστικά

  1. Κάτω πλευρά του πηγουνιού για μπάρες
  2. Κοντινό πλάνο της βάσης της ουράς για σημεία που φαίνονται στραβά
  3. Άνοιγμα ουράς για να φαίνεται το σχήμα της άκρης
  4. Νεαρά: καταγράψτε τυχόν κάθετες γραμμές

Όταν δεν είναι ξεκάθαρο

Οι νεανικές μαύρες ραβδώσεις στο τύμπανο ξεθωριάζουν με την ηλικία και οι κόκκινες χάνουν εντελώς τις κηλίδες τους κάποια χρόνια — οι μπάρες στο πηγούνι παραμένουν σταθερές. Τα μεγάλα κόκκινα και τα μαύρα τύμπανα επικαλύπτονται σε μέγεθος και νερό.

Τα εργαλεία αναγνώρισης μπορεί να είναι λανθασμένα. Επιβεβαιώστε τα αβέβαια ψάρια με την τοπική αλιευτική αρχή πριν βασιστείτε στο αποτέλεσμα για τους κανόνες συγκομιδής ή κατοχής.

Συχνές ερωτήσεις

Ποιο «χτυπάει τύμπανα» πιο δυνατά;
Τα μαύρα τύμπανα είναι τα πιο δυνατά κρώξιμο· μπορείς να τα ακούσεις μέσα από το κύτος ενός σκάφους τις ήρεμες μέρες.
Ποιο είναι το αγαπημένο του τραπεζιού;
Τα κόκκινα τύμπανα (ως «κοκκινόψαρο») κυριαρχούν στα μενού του Κόλπου. Τα μικρά μαύρα τύμπανα (μαύρα σε μέγεθος «puppy drum») επίσης έχουν καλή βαθμολογία - τα μεγάλα μαύρα γίνονται τραχιά.
Υβριδίζονται;
Δεν υπάρχουν επιβεβαιωμένα υβρίδια. Τα δύο διακρίνονται εύκολα από τις μπάρες και τις κηλίδες στα μάτια.
