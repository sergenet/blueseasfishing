Σπίτι / Γραφικό στοιχείο αναγνώρισης ψαριού

Δωρεάν widget fish-ID για τον ιστότοπό σας

Δώστε στους αναγνώστες σας άμεση αναγνώριση ψαριών: ένα πλαίσιο μεταφόρτωσης φωτογραφιών με αποτελέσματα τεχνητής νοημοσύνης, συνδέσμους ειδών και προτάσεις δολώματος — φιλοξενείται στους διακομιστές μας, ένα απόσπασμα για επικόλληση. Χωρίς κλειδί API, χωρίς συντήρηση, δωρεάν για ιστολόγια, ιστότοπους ναύλωσης, καταστήματα με είδη ψαριών και φόρουμ.

Ζωντανή επίδειξη

Γρήγορη εκκίνηση

  1. Επικολλήστε αυτό εκεί που πρέπει να εμφανίζεται το γραφικό στοιχείο:
    /div>
  2. Αυτό είναι όλο. Το τμήμα κώδικα αποδίδει ένα iframe στο φιλοξενούμενο αναγνωριστικό μας. Τα αποτελέσματα ανοίγουν σελίδες ειδών στον ιστότοπό μας σε νέα καρτέλα.

Καλό να γνωρίζουμε

  • Για ποιον είναι: Ιστολόγια αλιείας, ιστότοποι ναύλωσης και οδηγών, καταστήματα με είδη αλιείας, λέσχες και φόρουμ. Μην το μεταπωλείτε ως δικό σας προϊόν.
  • Ποσοστό: Οι επισκέπτες σας μοιράζονται την τυπική δωρεάν ποσόστωση (3 ID/ημέρα ανά επισκέπτη), η οποία εφαρμόζεται ανά IP — τα ίδια όρια δίκαιης χρήσης με το κύριο εργαλείο.
  • Απόδοση: Κρατήστε τη γραμμή "Powered by Blue Seas Fishing" στο γραφικό στοιχείο. Αυτή είναι η συνολική τιμή.
  • Μυστικότητα: Οι μεταφορτώσεις μεταφέρονται στο API μας μέσω HTTPS, υποβάλλονται σε επεξεργασία μόνο για ταυτοποίηση και δεν δημοσιεύονται ποτέ χωρίς άδεια. Το γραφικό στοιχείο δεν ορίζει δικά του cookie παρακολούθησης.

Συχνές ερωτήσεις

Κοστίζει κάτι;

Όχι. Το γραφικό στοιχείο είναι δωρεάν με αναφορά. Οι ιστότοποι με μεγάλη επισκεψιμότητα (100.000+ μηνιαίες φορτώσεις γραφικού στοιχείου) θα πρέπει επικοινωνήστε μαζί μας για μια ειδική ποσόστωση.

Μπορώ να το στυλίσω;

Ναι — το κοντέινερ iframe δέχεται το CSS σας (πλάτος, περιγράμματα, ακτίνα). Το ίδιο το περιβάλλον χρήστη του εργαλείου φιλοξενείται σε εμάς, επομένως οι βελτιώσεις εφαρμόζονται αυτόματα σε κάθε ενσωμάτωση.

Λειτουργεί σε κινητό;

Ναι — είναι ευέλικτο. Στα τηλέφωνα, πατώντας το πλαίσιο μεταφόρτωσης, οι επισκέπτες μπορούν να επιλέξουν να τραβήξουν μια φωτογραφία με την κάμερα ή να επιλέξουν μια υπάρχουσα φωτογραφία από τη βιβλιοθήκη τους.

Θα επιβραδύνει την σελίδα μου;

Το σενάριο φόρτωσης είναι ~1 KB και το iframe φορτώνεται αργά μόνο όταν γίνεται κύλιση κοντά του.

Θέλετε το αναγνωριστικό σε κάθε σελίδα;

Συνδέστε οποιοδήποτε όνομα ψαριού στον ιστότοπό σας απευθείας με τα 548 προφίλ ειδών μας.
