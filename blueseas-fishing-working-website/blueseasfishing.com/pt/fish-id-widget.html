Widget gratuito de identificação de peixes para o seu site

Ofereça aos seus leitores identificação instantânea de peixes: uma caixa para upload de fotos com resultados de IA, links para as espécies e sugestões de iscas — hospedada em nossos servidores, um único trecho de código para colar. Sem chave de API, sem manutenção, gratuito para blogs, sites de pesca esportiva, lojas de artigos de pesca e fóruns.

Demonstração ao vivo

Início rápido

  1. Cole este texto onde o widget deve aparecer:
    <!-- Blue Seas Fishing — Widget de identificação de peixes por IA -->
  2. É isso. O trecho de código renderiza um iframe para o nosso identificador hospedado; os resultados abrem as páginas das espécies em nosso site em uma nova aba.

Opções

AtributoPadrãoDescrição
altura dos dados640Altura inicial do iframe em px. O iframe se ajusta automaticamente para exibir os resultados (máximo de 4000 px).
alvo de dados (breve)—Reservado: direcione os resultados diretamente para as páginas das suas espécies.

Bom saber

  • Para quem é indicado: Blogs de pesca, sites de guias e serviços de charter, lojas de artigos de pesca, clubes e fóruns. Por favor, não revenda como se fosse seu próprio produto.
  • Contingente: Seus visitantes compartilham a cota gratuita padrão (3 IDs/dia por visitante), aplicada por IP — os mesmos limites de uso justo da ferramenta principal.
  • Atribuição: Mantenha a linha "Powered by Blue Seas Fishing" no widget; esse é o preço total.
  • Privacidade: Os dados enviados são encaminhados para nossa API via HTTPS, processados apenas para identificação e nunca publicados sem permissão. O widget não define nenhum cookie de rastreamento próprio.

Perguntas frequentes

Tem algum custo?

Não. O widget é gratuito, desde que seja feita a atribuição. Sites com alto tráfego (mais de 100 mil acessos mensais ao widget) devem Contate-nos para uma quota dedicada.

Posso estilizar?

Sim — o contêiner iframe aceita seu CSS (largura, bordas, raio). A interface do usuário da ferramenta em si está hospedada conosco, portanto, as melhorias são implementadas automaticamente em todas as incorporações.

Funciona em dispositivos móveis?

Sim, é responsivo. Em celulares, ao tocar na caixa de upload, os visitantes podem optar por tirar uma foto com a câmera ou escolher uma foto existente da biblioteca.

Isso vai deixar minha página mais lenta?

O script de carregamento tem cerca de 1 KB e o iframe é carregado de forma assíncrona, apenas quando a pessoa rola a página para perto dele.

Prefere que o identificador apareça em todas as páginas?

Vincule qualquer nome de peixe em seu site diretamente aos nossos 548 perfis de espécies.
