Comment identifier un chinchard

Le chinchard se rencontre dans les baies côtières, les estuaires, les plages, les jetées, les récifs et les eaux du plateau continental. Utilisez ces caractéristiques comme point de départ et comparez-les avec un guide d'identification complet avant de vous fier à toute identification.
