Comment identifier un poisson-lézard côtier

Les poissons-lézards côtiers se rencontrent sur les plateaux continentaux, les récifs, les fonds sableux, vaseux, les herbiers marins ou estuariens, selon l'espèce. Utilisez ces caractéristiques comme point de départ et comparez-les avec un guide d'identification complet avant de vous fier à toute identification.
